# Code of Conduct

This is a small project. The rules are short.

## What is expected

Be civil. Assume the other person is trying to help. Criticise the code, not the person.
When you disagree, say what you would do instead and why.

Keep discussion on the topic: reverse engineering, signature generation, Cheat Engine.
Questions from beginners are welcome; nobody was born knowing what a displacement is.

## What is not acceptable

Personal attacks, harassment, or slurs of any kind. Deliberately derailing threads.
Publishing someone's private information. Using issues or pull requests to advertise
unrelated products.

## Scope

This applies to everything in this repository: issues, pull requests, discussions and
commit messages.

## Reporting

Open an issue, or write to the address on the maintainer's GitHub profile if the matter is
better handled privately. Reports are read by the maintainer and nobody else.

Consequences are at the maintainer's discretion and range from a request to change tone, to
having a comment removed, to being blocked from the repository. Repeat behaviour after a
warning will be treated as intent, not accident.
